FediQB (Fediverse Question Box)

分散型SNSのアカウントを利用して、匿名の質問箱を簡単に作成できるサービスです。SNS上のプロフィールと連携し、ファンやフォロワーからの質問を受け付けられます。

Go Python TypeScript (React)
Tootori (トゥートリ)

Fediverse連携型の「絵しりとり」アプリ。ルーム制を採用しており、公開ルームの一覧から参加したり、あいことばで閉じた部屋を作ったりできます。DMでの更新通知機能も備えています。

Go TypeScript (React)
llm-translate

LLM（大規模言語モデル）をLibreTranslate API互換のサーバーとして動作させ、Mastodon等のアプリから翻訳機能として利用できるようにする自作のプロキシ。Hy-MT2などのモデルに対応し、38言語の翻訳をローカル環境で実現します。

Go Docker llama.cpp GitHub
